# idk plus — لوحة الأكواد

لوحة عربية متجاوبة وخدمة تفعيل مخصصة لـ Cloudflare Workers + D1.

## شنو الجاهز؟

- كود 12 خانة بالمجموع: `idk` + تسع خانات عشوائية من الحروف والأرقام الواضحة.
- تسجيل دخول للمالك، توليد اشتراك باسم المشترك ومدته ومعرّف تثبيت التطبيق.
- مفتاح Ed25519 يبقى في ذاكرة متصفح المالك؛ لا يُرفع إلى السيرفر ولا يُحفظ بالمتصفح.
- الخادم يتحقق من توقيع التفعيل قبل توليد الكود، والتطبيق يتحقق منه مرة أخرى قبل فتح المتجر.
- قاعدة البيانات تحتفظ ببصمة الكود، وليس الكود كاملًا. يظهر الكود كاملًا مرة واحدة عند إنشائه.
- التفعيل مرتبط بمعرّف تثبيت التطبيق نفسه؛ هذا المعرّف ليس UDID.
- تعطيل كود يمنع استخدامه للتفعيل مستقبلًا. الاشتراك المحفوظ على جهاز مفعّل مسبقًا يبقى صالحًا إلى نهايته؛ هذه النسخة لا تدّعي إلغاء الاشتراك المحفوظ فورًا.
- حماية من التخمين، منع الكتابة من أصل مختلف، وحدود لأحجام الطلبات، و100 اشتراك بكل صفحة.

## الربط من الموبايل بدون توكن Cloudflare

1. افتح Cloudflare → Workers & Pages → Create application → Import repository.
2. اختَر مستودع `NEXT11DEV/APPNEXT` وفرع **idk-panel**. هذا الفرع مشروع اللوحة فقط، وليس مشروع بناء الآيفون.
3. اسم Worker: **idk-plus-panel**، ومجلد المشروع الجذر `/`. أمر البناء: **npm test**. أمر النشر: **npm run deploy**.
4. إعداد `wrangler.jsonc` يطلب إنشاء قاعدة D1 وربطها باسم **DB** تلقائيًا. اسم القاعدة **idk-plus-licenses**. إذا طلب Cloudflare الموافقة على إنشاء القاعدة، اختَر إنشاء وربط هذه القاعدة. لا تغيّر موارد مشاريعك الأخرى.
5. من Worker → Settings → Variables and Secrets، أضف **Secret** باسم **ADMIN_KEY**. استخدم قيمة عشوائية من 24 خانة أو أكثر؛ ليست كلمة مرور حساب Cloudflare. احفظها عندك ولا ترسلها بالمحادثة أو GitHub. الصفحة الرئيسية للوحة تتضمن مولّدًا محليًا لقيمة عشوائية مناسبة إذا احتجت.
6. أعد نشر العامل بعد حفظ السر. افتح رابط **workers.dev** الظاهر في Cloudflare. أدخل مفتاح الإدارة؛ أول دخول ينشئ جداول هذه اللوحة فقط.
7. فك حزمة المالك الخاصة عندك واختَر ملف `owner-private-key.pem` من داخلها. تحقّق اللوحة من مطابقته لمفتاح idk plus، محليًا في المتصفح. إذا المتصفح لا يدعم Ed25519، تستطيع استخدام أداة المالك الحالية ثم لصق التفعيل الطويل من الخيار البديل.
8. أدخل اسم المشترك ومعرّف جهازه ومدته، ثم انسخ الكود القصير وأرسله له.

**اللوحة ليست منشورة لمجرد رفع هذا الفرع إلى GitHub.** يلزم إكمال الربط والنشر داخل حساب Cloudflare.

### إذا تعذّر إنشاء D1 تلقائيًا

من Storage & Databases → D1، أنشئ قاعدة `idk-plus-licenses`. انسخ معرّفها إلى الحقل `database_id` داخل عنصر `d1_databases` في `wrangler.jsonc` ثم أعد النشر. لا يوجد معرّف حساب أو قاعدة مفترض داخل هذا المستودع. Wrangler مثبّت إلى 4.45.0 لدعم إنشاء الموارد التلقائي.

## ربط نسخة الآيفون

النسخة الحالية 1.5 لا تدعم الأكواد القصيرة بعد. بعد ظهور رابط Worker الحقيقي، طبّق الملفين داخل `ios-integration` على مشروع الآيفون وأضف المفتاح `IDKActivationURL` في Info.plist مع أصل HTTPS الحقيقي للـWorker (بدون `/api/redeem`). ثم ابنِ IPA جديدًا؛ الملفات تحافظ على تفعيل IDK1 القديم ومعرّف التطبيق.

لا تضع ADMIN_KEY أو مفتاح المالك أو ملفات P12 في Info.plist أو نسخة الآيفون أو المستودع.

## التشغيل والتحقق

Node.js 24 لاختبارات SQLite المدمجة:

```sh
npm test
```

للتطوير المحلي، ضع ADMIN_KEY فقط في ملف `.dev.vars` غير المتتبع ثم:

```sh
npm run dev
```

مسارات الخدمة:

- GET `/` لوحة المالك. إتاحة HTML لا تمنح أي صلاحية لإدارة الاشتراكات.
- POST `/api/admin/setup` تهيئة بعد إثبات مفتاح الإدارة.
- GET/POST `/api/admin/licenses` عرض/إنشاء أكواد.
- PATCH `/api/admin/licenses/:id` منع/سماح بالتفعيل.
- POST `/api/redeem` مع `{code, subject}` يرجّع التفعيل الموقّع للجهاز المطابق.

استجابة التفعيل لا تُحفظ في Cache، ولا توجد واجهة عامة تسرد الأكواد أو المشتركين. HTTPS إلزامي في ربط التطبيق. يعمل تنظيف سجلات محاولات التخمين كل ساعة. كود قصير واحد لا يحل محل شهادة P12 أو ملف provisioning.
