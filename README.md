# TAIF PLUS — الموقع ولوحة الاشتراكات

نسخة مستقلة عن idk plus. اسم العامل taif-plus-panel، وقاعدة البيانات taif-plus-licenses مع binding باسم DB. تحتوي موقعًا عامًا أحمر/أبيض/فحمي وتصفح التطبيقات، ولوحة مالك ومفوضين وربط شهادات. لا تحتوي بيانات مشتركين أو مفاتيح خاصة.

## الربط على Cloudflare

أنشئ Worker جديدًا باسم taif-plus-panel واربط مستودع NEXT11DEV/APPNEXT وفرع taif-panel. لا تغيّر إعدادات عامل idk-plus-panel القديم.

- Root: /
- Build: npm test
- Deploy: npm run deploy

إذا اختار Cloudflare الفرع القديم، استعمل أمر البناء: git fetch origin taif-panel && git checkout --detach FETCH_HEAD && npm test

اربط قاعدة D1 مستقلة باسم taif-plus-licenses كمتغير DB. افتح /admin، أدخل اسم وكلمة مرور تختارها لأول مرة ثم ملف المالك الخاص بـ TAIF PLUS لإثبات الملكية. الحساب ينحفظ بقاعدة البيانات الخاصة. لا تنشر الملف الخاص.

إصدار الأكواد TAIF1 وتفعيلها بـ12 خانة تبدأ taif. مفاتيح idk القديمة وأكوادها لا تفعّل TAIF PLUS. لإضافة شهادات المشتركين، أضف Secret باسم CERTIFICATE_KEY بقيمة عشوائية 24 خانة أو أكثر، واحتفظ بها بدون تغيير حتى لا تحتاج إعادة رفع الشهادات.

المالك يدير المفوضين ويشاهد أكوادهم ويوقف الحساب أو الأكواد أو الاثنين. المفوض يرى أكواده فقط. مشاركة ملف المالك تظل تمنحه إمكانية إصدار أكواد طويلة خارج اللوحة؛ إلغاء الحساب يوقف دخوله إلى الخدمة فقط.

## البناء

Node 24 ثم npm test. مكتبة التطبيقات وأصل الشعار يتجمعان من أجزاء عامة، وWrangler مثبت بالإصدار 4.45.0. نسخة TweetNaCl.js 1.0.3 موجودة محليًا للتوافق مع متصفحات iOS القديمة، مع ترخيصها.

## نشر سريع لخدمة TAIF المستقلة

[بدء إعداد TAIF على Cloudflare](https://deploy.workers.cloudflare.com/?url=https%3A%2F%2Fgithub.com%2FNEXT11DEV%2FAPPNEXT%2Ftree%2Ftaif-panel)

هذه خطوة إعداد وليست رابط لوحة منشورة بالفعل. أبق اسم العامل `taif-plus-panel` حتى يتطابق مع رابط التفعيل داخل التطبيق. إن ظهر اختيار الفرع، اختر `taif-panel`، وليس `main`. أمر النشر `npm run deploy`، والجذر `/`.

تحتاج الخدمة قاعدة D1 خاصة بـ TAIF مرتبطة باسم `DB`. إذا لم تُنشأ تلقائيًا، أنشئ `taif-plus-licenses` ثم اربطها من Bindings. لا تستخدم قاعدة أو مفتاح مالك idk. بعد نجاح النشر افتح `/api/health` ويجب أن يظهر `TAIF PLUS`، ثم `/admin` لإعداد حساب المالك بمفتاح TAIF الخاص.

الأكواد الجديدة 12 خانة تبدأ `TAIF` بأحرف كبيرة. الإدخال يقبل حالة الأحرف المختلفة، والتخزين يستخدم الصيغة الموحّدة السابقة لحفظ توافق الأكواد الموجودة. الكود الطويل TAIF1 ما زال يعمل دون خدمة الأكواد القصيرة.
